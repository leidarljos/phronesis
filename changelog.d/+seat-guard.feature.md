A write onto a file the seat keeps for itself warns as `seat-guard-path: PATH`: the agent hook files, the ljos and ljos-policyd config directories, the ljos git hooks directory and the global git config, written by a redirection, tee, cp, mv, dd, sed -i, tar or unzip into the directory, an inline program, or `core.hooksPath` set globally. A link made with `ln` earlier on the line is followed.
