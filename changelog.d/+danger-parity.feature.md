The pack's danger and tree rules answer with the rule id alone (`rm-rf-outside-tmp`, `git-force-push`, `sudo`), the token ljos-policyd publishes. Further, ported from its built-in table: `find -exec rm` is `find-exec-rm` apart from `find-delete`; a download piped into Python is `curl-pipe-python`; a recursive rm, srm, wipe or trash of `/` or a home directory, and a delete behind strace or another tracer, is `rm-rf-outside-tmp`; a git `-c` value git runs, or an alias naming the subcommand, is judged as what it runs; and a privilege runner is judged by the command it runs first.
